Temperature history — 2 series, targets as reference lines

Two entities (bed, hotend), not four series: the target is a dashed reference on the same hue, so the identity channel stays at two. One axis, always — never a second y-scale.

  • lines 2px, round join/cap; targets 1.5px dashed on the same hue
  • end markers r=4 with a 2px surface ring; direct end labels in ink, never the series colour
  • gridlines solid hairlines one step off surface — never dashed
  • y ticks snap to clean multiples; container height includes the x-axis band
  • colliding end labels get a leader line, never a silent vertical stack

Bed mesh — diverging, not sequential

A mesh value has polarity: above or below the reference plane. Two opposite poles with a neutral gray midpoint and a symmetric domain around zero. Every cell is labelled, so the heatmap doubles as its own table view.
