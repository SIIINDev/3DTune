# 3DTune design system

Источник истины для внешнего вида [`web/`](../web/). Каждый файл — самодостаточное превью,
открывается двойным кликом, работает офлайн, без сборки и без CDN.

Первая строка каждого файла — маркер `<!-- @dsCard group="…" -->`. По нему панель
Design System на claude.ai строит карточки, поэтому маркер удалять нельзя.

| [foundations/type-and-figures.html](foundations/type-and-figures.html) | Шрифтовая шкала и правило пропорциональных / табличных цифр |

## Синхронизация с claude.ai/design

Проект: **Design System** (`43041a7d-e07b-4cd1-ac0f-6f1e3a8f660e`), тип
`PROJECT_TYPE_DESIGN_SYSTEM`. Доступ уже выдан — отдельная настройка не нужна.

Заливка идёт по одному компоненту за раз, не заменой всего проекта целиком:

1. прочитать текущее состояние проекта (`list_files`), собрать структурный diff;
2. согласовать точный список путей — на этом шаге показывается диалог подтверждения;
3. записать файлы.

## Правила, которые нельзя нарушать

Они не косметические — каждое стоит за конкретным анти-паттерном:

- **Две категориальные серии, фиксированный порядок.** Стол — слот 1 (синий), сопло — слот 2
  (оранжевый). Цель нагрева не третья серия, а пунктирная референсная линия того же тона.
- **Палитра меняется только вместе с прогоном валидатора** в обеих темах, против фактических
  поверхностей `#fcfcfb` / `#1a1a19`. Текущий худший соседний зазор: CVD ΔE 24.7 / 26.8 при
  пороге 8, normal-vision 33.6 / 31.8 при пороге 15.
- **Сетка стола — diverging, а не радуга и не однотонный ramp.** Значение имеет знак:
  выше или ниже плоскости. Нейтральный серый в нуле, симметричный домен.
- **Крупные числа — пропорциональными цифрами.** `tabular-nums` только там, где цифры
  выравниваются по вертикали: оси, строки таблиц, инпуты, тултипы, ячейки сетки.
- **Текст не носит цвет данных.** Идентичность даёт цветная метка рядом. Исключение — подпись
  внутри залитой ячейки, там цвет выбирается по светлоте фона.
- **Статусные цвета зарезервированы** и всегда идут с иконкой и подписью, никогда цветом одним.
- **Сетка и оси — сплошные волосяные линии**, никогда пунктир: пунктир читается как порог.
- **Тач-цели минимум 44px.** Управление ведётся с телефона, иногда грязными руками.
