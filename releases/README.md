## Что нужно на машине

**Node.js 24 или новее** — https://nodejs.org, LTS-версия, галочки при установке менять не надо.
Это единственная зависимость. Лаунчер проверяет её сам и, если Node нет или он старый,
пишет что именно скачать, а не падает с непонятной ошибкой.

Если ставить Node не хочется — рантайм можно вложить внутрь сборки, тогда на машине
не нужно вообще ничего:

```bash
node scripts/build-portable.mjs --target win-x64 --with-node 24.19.0 --zip
```

Получится ~34 МБ вместо 0.7 МБ. В репозиторий такие сборки не кладутся: они бы навсегда
осели в истории git и утяжелили клонирование для всех.

## Запуск

**Windows** — распаковать и запустить `Запустить-3DTune.bat`.
При первом старте Windows спросит про брандмауэр: разрешить для **частных** сетей,
иначе телефон и другие устройства не достучатся. Подробности, включая драйвер CH340 для
USB-кабеля, — в [docs/WINDOWS_QUICKSTART.md](../docs/WINDOWS_QUICKSTART.md).

**macOS** — распаковать и запустить `Запустить-3DTune.command`. Первый раз macOS может
сказать «неизвестный разработчик»: правый клик по файлу → «Открыть» → «Открыть».

Лаунчер проверит окружение, при первом запуске поставит зависимости, поднимет сервер
и откроет браузер. Что делать дальше — в [README проекта](../README.md).

Проверить готовность, ничего не запуская:

```bash
node bin/3dtune.mjs --doctor
```

## Что проверено, а что нет

Сборки собраны из `scripts/build-portable.mjs` и воспроизводимы из исходников:
`npm run build:win`, `npm run build:mac`.

- **darwin-arm64** — распакована и запущена: `--doctor` проходит, сервер стартует,
  интерфейс работает против встроенного эмулятора Marlin.
- **win-x64** — проверен состав архива (нативный модуль ровно под `win32-x64`, оба лаунчера
  на месте), но **на настоящей Windows не запускался**. Первый реальный запуск `.bat`
  остаётся открытым пунктом; самое вероятное место спотыкания — брандмауэр.
- **darwin-x64** — собран из того же кода и того же универсального нативного модуля,
  что и arm64, но на Intel-маке не запускался.

И общее: приложение целиком проверено против **эмулятора**, а не против принтера.
Перед первым нагревом и движением на живом KP5L пройди
[docs/PHASE0_DISCOVERY.md](../docs/PHASE0_DISCOVERY.md) — 20 минут, и она определяет,
не придётся ли часть допущений переписывать.
