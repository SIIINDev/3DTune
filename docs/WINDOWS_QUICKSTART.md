# Первый запуск на Windows

Установщика в привычном виде (`setup.exe`) здесь нет намеренно. 3DTune — локальный сервер, а не
приложение: ему не нужны права администратора, служба, запись в реестр или изменение PATH.
Достаточно папки и одного файла запуска. Удаление — удалить папку.

## Что нужно один раз

**1. Node.js.** Единственная внешняя зависимость.
Открой [nodejs.org](https://nodejs.org), скачай LTS для Windows, установи, галочки не меняй.

**2. Драйвер CH340.** Плата KP5L общается по USB через микросхему CH340.
Windows 10/11 обычно ставит драйвер сам. Если в диспетчере устройств принтер виден как
«неизвестное устройство» — поставь драйвер [от WCH](https://www.wch-ic.com/downloads/CH341SER_ZIP.html).

**3. Кабель.** Нужен тот, который идёт от компьютера к разъёму на плате принтера.
Кабель зарядки телефона не подойдёт, если он только для питания.

## Запуск

Двойной клик по **`Запустить-3DTune.bat`** в папке проекта.

Он сам:
1. проверит версию Node.js;
2. при первом запуске установит зависимости (одна минута, только один раз);
3. прогонит проверку готовности и **не запустится**, если что-то блокирующее;
4. запустит сервер, открытый для локальной сети, и откроет браузер.

Первый запуск Windows спросит про доступ к сети для Node.js. **Разреши для «Частных сетей»** —
без этого телефон и мак не подключатся. Окно появляется один раз.

Если окно не появилось, а с других устройств не открывается:
Защитник Windows → Брандмауэр и защита сети → Разрешить работу с приложением через брандмауэр →
найди Node.js → поставь галочку «Частная».

## Проверка без запуска

```bash
node bin\3dtune.mjs --doctor
```

Проверяет по пунктам: версию Node, зависимости, файлы интерфейса, конфиг и права на него,
свободен ли порт, видны ли последовательные порты, есть ли адрес в локальной сети.
У каждого сбоя написано, что именно с ним делать.

## Управление с телефона, мака и другого ПК

Работает, ничего дополнительно ставить не надо: на других устройствах нужен только браузер.

1. На компьютере с принтером в 3DTune открой карточку **«Подключить устройство»** →
   **«Показать код»**.
2. На телефоне или маке открой адрес из списка там же, например `http://192.168.1.50:8420`.
   Адреса, помеченные «возможно, виртуальный адаптер», пропускай — это VPN и служебные интерфейсы.
3. Введи 6-значный код.

Код живёт 5 минут, срабатывает один раз и отменяется после нескольких неверных попыток.
После ввода устройство помнит доступ, повторно вводить не нужно.

**Важно про кабель.** Доступ по сети не отменяет USB: провод держит одна машина, остальные —
клиенты в браузере. Если Windows-ПК стоит рядом с принтером и включён, это и есть правильная
схема: ядро на нём, мак и телефон подключаются браузером.

## Чего делать не надо

- **Не выставляй наружу в интернет.** Это управление нагревателем на 250 °C. Никаких проброшенных
  портов. Нужен доступ извне — только VPN, и это твоя ответственность.
- Токен внутри локальной сети идёт по обычному HTTP. На домашнем Wi-Fi это приемлемо, на публичном
  или гостевом — нет.
- Если потерял доверие к токену: `node bin\3dtune.mjs --rotate-token`. Все прежние ссылки и
  подключённые устройства перестанут работать.

## Автозапуск (по желанию)

Ярлык на `Запустить-3DTune.bat` в папке автозагрузки:
`Win+R` → `shell:startup` → положить туда ярлык.

Служба и планировщик не нужны: 3DTune рассчитан на то, что окно видно и его можно закрыть.

## Если что-то не так

| Симптом | Причина |
|---|---|
| «Node.js не найден» | Node не установлен или установлен без добавления в PATH — переустанови |
| «Порт занят» | 3DTune уже запущен в другом окне, либо порт занят чужой программой: `--port 8421` |
| Принтер не в списке портов | Кабель, питание принтера или драйвер CH340 |
| «порт уже открыт в другой программе» | Закрой слайсер или терминал, который держит COM-порт |
| С телефона не открывается | Брандмауэр Windows, либо устройства в разных сетях, либо гостевой Wi-Fi с изоляцией клиентов |
| Открывается, но просит код | Так и задумано: введи код из карточки «Подключить устройство» |
