# 3DTune

Управление и настройка 3D-принтера **Kingroon KP5L** по USB — PID, геометрия, 3D Touch, сетка
стола, калибровки — из веб-интерфейса, доступного с любого устройства в локальной сети.
Тачскрин принтера не нужен.

**Статус:** Фазы 1–3 реализованы против эмулятора, Фаза 4 начата с мастера E-steps.
Все программные критерии из [PROD_READINESS](docs/PROD_READINESS.md) закрыты, программного долга
из [BACKLOG](docs/BACKLOG.md) §1 не осталось, тесты и CI зелёные.
Разработка идёт против встроенного эмулятора Marlin — принтер и кабель для этого не нужны.

**Два гейта закрываются только вживую и остаются открытыми:**
[Фаза 0](docs/PHASE0_DISCOVERY.md) на самом KP5L (20 минут, **обязательна перед первым нагревом и
движением**) и первый реальный запуск `.bat` на машине с Windows — скрипт вычитан, но исполнялся
только с macOS-стороны.

## Запуск

### Windows и macOS в один клик

Двойной клик по **`Запустить-3DTune.bat`** (Windows) или **`Запустить-3DTune.command`** (macOS).
Лаунчер проверит Node, при первом запуске поставит зависимости, прогонит проверку готовности,
запустит сервер для локальной сети и откроет браузер. Установщика, прав администратора и служб
не требуется — удаление это удаление папки.

Подробно, включая брандмауэр Windows и драйвер CH340:
**[docs/WINDOWS_QUICKSTART.md](docs/WINDOWS_QUICKSTART.md)**.

Проверить готовность, ничего не запуская:

```bash
node bin/3dtune.mjs --doctor
```

### Собрать переносимую сборку

Один каталог, который запускается без установки и без компиляции. Удаление — удалить папку.

```bash
npm run build:win
```

`dist/3dtune-<версия>-win-x64/` — 1.8 МБ, внутри всё нужное, требуется установленный Node 24+.
Чтобы Node не требовался вовсе, вложи рантайм внутрь:

```bash
node scripts/build-portable.mjs --target win-x64 --with-node 24.19.0 --zip
```

Получится ~117 МБ: папка с `runtime/node.exe`, лаунчеры сами предпочтут его системному.
Компилятор не нужен — `serialport` поставляет готовые бинарники под все платформы, поэтому
Windows-сборка собирается с macOS или Linux.

### Вручную

Нужен только Node 24+ (типы стираются рантаймом, сборки нет).

```bash
npm install
```

Против встроенного эмулятора Marlin — ничего подключать не надо:

```bash
npm run mock
```

В консоли появится ссылка с токеном (`http://127.0.0.1:8420/#t=…`) — открой её в браузере.

С реальным принтером:

```bash
node bin/3dtune.mjs --list-ports
```

```bash
node bin/3dtune.mjs --serial /dev/cu.usbserial-1420 --baud 115200
```

Доступ с телефона и других устройств в локальной сети:

```bash
node bin/3dtune.mjs --serial /dev/cu.usbserial-1420 --host 0.0.0.0
```

Сервер напечатает LAN-ссылки. Чтобы подключить телефон или мак: карточка «Подключить устройство» →
«Показать код», на другом устройстве открыть адрес и ввести 6 цифр. Код живёт 5 минут, срабатывает
один раз и отменяется после нескольких неверных попыток — 22-символьный токен руками вводить не надо.

**Наружу в интернет не выставлять** — это управление нагревателями; нужен удалённый доступ, VPN.

Прогон с имитацией помех на линии (проверка восстановления по `Resend`):

```bash
npm run mock:chaos
```

Тесты и типы:

```bash
npm test && npx tsc --noEmit
```

| **Интерфейс** | шесть разделов: обзор, стол и зонд, калибровки, настройка с нуля, слайсер, терминал. Выбранный раздел переживает перезагрузку |

| **Диагностика прошивки** | по `M115 Cap:` и `M503` приложение само предупреждает: `EMERGENCY_PARSER` выключен, EEPROM недоступен, стол в bang-bang, зонда нет в прошивке |

## Короткая версия вердикта

Реализуемо, сложность средняя. Канал — `SERIAL_PORT 3` → CH340 → USB, 115200; тачскрин UART не
занимает, порт наш целиком.

**3DTune — это хост, а не прошивка.** Параметры (PID, шаги/мм, offset зонда, сетка, Z-offset)
настраиваются по USB и сохраняются в EEPROM. А *включение* самого 3D Touch, алгоритм левелинга и
лимиты температур — параметры времени компиляции.

Хорошая новость из исследования: стоковые архивы KP5L «autolevel» и «manual level» содержат
**побайтово одинаковый** `Robin_nano.bin` и различаются **одной строкой** в `robin_nano_cfg.txt`
(`cfg_leveling_mode 0` → `1`). Если Фаза 0 подтвердит поддержку зонда в стоке, включение 3D Touch —
правка текстового файла на SD-карте, а не пересборка.

Ещё: доступ по локальной сети **не отменяет USB-кабель** — кабель держит одна машина (Windows-ПК,
мини-хост или мак с кабелем USB-C→USB-B), остальные подключаются браузером. Подробнее — PLAN §3.
